# OriTV

TV-first web application for LG webOS / Media Station X.

Live site: https://itos11.github.io/oritv/

## Current build

- TV-first responsive interface
- LG Magic Remote / 5-way keyboard navigation
- Home, History, Movies, Series, Cartoons, Anime, Favorites, Settings
- Search
- Movie/series detail screen
- Local history and favorites via localStorage
- Local SVG poster assets with visual fallbacks
- Blue + orange OriTV visual style
- MXS launcher files in `msx/`

## Sources

The catalog is intentionally demo data. Real movie/series sources can be connected later in `config.js` and the player/source layer without rebuilding the UI.
